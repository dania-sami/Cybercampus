# Common Ground
Dania Sami — Communication and collaboration work sample

## Open
Extract the ZIP and double-click index.html, or open the folder in VS Code and use Go Live. No installation, API keys or internet connection is needed for the prototype.

## The idea
One Cybercampus-inspired communication problem, four stakeholder perspectives and three possible approaches. The prototype demonstrates listening, clarifying questions, different messages for different audiences and a shared next-step proposal.

This is a fictional scenario, not a record of real stakeholder conversations or an official Cybercampus tool.

## A two-minute demonstration
1. In Listen first, reveal the university partner's perspective and clarifying question.
2. In Find a way forward, compare a staged update with postponing the announcement. Add your reasoning.
3. In Adapt the message, switch from the university partner to the learner liaison. Notice how the facts stay consistent while the emphasis changes.
4. In Close the loop, show the pending approvals, proposed owners and contingency. Download the collaboration note.

## What works
- Four scenario stages and four stakeholder perspectives.
- Three selectable proposals, each with benefits, trade-offs, approval conditions and fallback.
- Editable, saved reasoning and audience-specific drafts.
- Browser-local persistence where supported.
- Downloadable Markdown collaboration note including your edits.
- Reset to the initial scenario.

Messages are drafts only. No emails are sent. All stakeholder confirmations remain pending. Browser restrictions can affect clipboard access and local-file storage; copy selected text manually if needed, or use Go Live. Export the note to retain a separate copy.
