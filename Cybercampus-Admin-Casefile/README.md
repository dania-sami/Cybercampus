# Cybercampus Administrative Case File
Dania Sami

## Start
1. Extract the ZIP completely.
2. Open `index.html` in a modern browser.

Alternatively, open the folder in VS Code, right-click `index.html`, and choose **Open with Live Server** (Go Live).

No installation, account, API key or build step is needed. The interface and records work offline. Opening the original university source links requires internet access.

## Working features
- Five navigable exhibits: assignment, evidence, decisions, organisation and handover.
- Searchable register with seven real course listings.
- Record detail dialogs with source links and next actions.
- Seven documented decisions and editable personal review notes.
- Five prepared follow-up requests, with editable text and clipboard copying.
- CSV register and Markdown handover downloads.
- Notes saved in this browser when local storage is available.

Clipboard access may be restricted when opening a local file. If copying is blocked, the draft is selected for manual copying. Browser storage policies can vary for local files; Go Live provides a consistent local origin. Export the handover to retain a separate copy of notes. Draft edits are temporary and are not saved when their dialog closes.

## Scope
An independent application work sample based on public sources reviewed on 6 October 2026. It demonstrates collection, structuring, review decisions, priorities and handover preparation. It is not an official Cybercampus product. No emails are sent, no university records are changed and no institutional approval is claimed. Course availability and unresolved offering details require confirmation.

The included CSV and Markdown files are baseline snapshots. The in-app handover download additionally includes any saved personal review notes.

## Files
- `index.html`: entry page
- `style.css`: responsive styling
- `evidence.js`: reviewed records, sources, decisions and actions
- `app.js`: navigation, dialogs, notes, search and exports
- `Dania-Sami-course-register.csv`: baseline register
- `Dania-Sami-administrative-work-sample.md`: baseline handover
